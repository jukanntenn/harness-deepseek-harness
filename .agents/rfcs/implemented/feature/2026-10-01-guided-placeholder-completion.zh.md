# RFC: 用引导式占位符补全被移植技能中的命令

Status: implemented

[English](2026-10-01-guided-placeholder-completion.md) | 中文

## 问题

被移植的技能把 hdsh 的具体工具链事实当作消费方的事实来陈述：pytest 调用与 tests/ 镜像布局、类型面用 basedpyright、未暂存文件的 ruff、钩子清单、打包冒烟、覆盖率工作流、本地全集的构成、hdsh 自己的归档测试路径，以及它的控制台入口测试惯例。对 Rust 或 Node 消费方这些全是死命令，而它们所代表的知识——行为改动跑什么、类型面跑什么、风格跑什么、打包跑什么——恰恰是每个仓库必须自己回答的问题。没有任何门禁看得见错误命令，也没有任何东西要求消费方替换它们。实测面是 pushing 与 archiving-rfcs 两个技能里的十处非 hdsh `uv run` 命令，外加钩子清单与入口路径两项事实。

## 决策

本 RFC 是[可迁移语料四分法](../architecture/2026-10-01-transplantable-corpus.zh.md)中"每个仓库各有一个值"一行在技能上的落地。

- **带命令的技能是槽位模板。** 审计点名 pushing（七个槽位：hooks、focused-tests、type-check、packaging-smoke、style-check、coverage、full-suite）、archiving-rfcs（archive-tests）与 reviewing（entry-path）。每个槽位是一个被标记的区域——`<!-- hdsh:slot <名> -->` 到 `<!-- /hdsh:slot -->`——其内容以引导式 `TODO(adopt):` 文本出厂，说明要声明什么并以 hdsh 自己的形态作为成例。槽位周边的散文被泛化：仓库名离开标题与描述，hdsh 命令以调用映射产出的消费方形态出现。
- **占位符检查是 always-run 的 prek 钩子。** `hdsh-adopt-verify` 运行 `hdsh adopt verify --hook`，把未填槽位与其他所有 `TODO(adopt):` 标记一并计数；没有接入 manifest 的仓库是一次性成功，因此该钩子绝不会在无人接入的地方失败。钩子与其他托管钩子一样携带 `hdsh` 组，hdsh 自己的 prek 配置同样运行它。
- **槽位在 re-apply 间持久。** apply 重渲染周边散文，并对每个槽位在指引未变时保留消费方的值；adopt manifest 以每个已装指引的 digest 作为基线。当某个槽位的上游指引变了而消费方已填过值，apply 把该槽位重置为新指引、按名报告重置，占位符钩子随即要求重填。槽位之外的消费方编辑属上游领地：re-apply 原样替换，与所有生成文件一致。
- **模板直接说消费方形态。** hdsh 命令在槽位模板里写裸形态，调用映射只作用于镜像。非 hdsh `uv run` 的作者拒绝——由语料程序暂缓到本程序使语料可满足为止——现已强制执行：自包含门禁拒绝镜像语料中的任何非 hdsh `uv run` 命令。

## 验证

聚焦测试钉住文法与流程：槽位解析读取多行区域并拒绝嵌套、失配标记、重名与空体；拼接替换内容并要求每个值都有；全新 apply 装入指引、manifest 记录逐槽位 digest，verify 要求补全；re-apply 保留已填值并如实报告、把记录基线失效的已填槽位重置并点名、对畸形的已装标记 blocker、把槽位外的消费方编辑替换而非拒绝、把缺失的槽位模板报为 drift；hook 模式在无 manifest 时为 no-op；自包含门禁现在证明镜像语料不携带任何开发命令。

## 备选方案

**泛化措辞并链接仓库自己的命令清单。** 否决：指针不是值，清单被跟随时可能未填或缺席，而 hdsh 自己的技能失去具体命令——这正是催生本 RFC 所实现的那一行四分法的缺陷。

**adopt 时机械改写命令。** 与其说否决不如说不可能：消费方的命令在接入时未知，没有可以改写进去的目标；只有消费方能陈述它们。

**填完后让整个技能变为可编辑。** 否决：这会把操作性语料冻结在接入时点，上游的技能修订从此再也无法到达已接入的仓库。

## 后果

本变更买到的东西：全新接入在填完每个命令槽位之前无法越过占位符钩子提交，而诊断即填写说明；换新 ref 的 re-apply 保留已填槽位并更新周边散文；上游对槽位本身的修改被按名报告并附重填动作；被审计的技能对任何消费方都不再携带死命令；镜像语料被证明不含 hdsh 开发命令。

本变更的代价：三个受影响技能存在两份——hdsh 活文件与泛化模板——其余技能仍靠镜像字节等价纪律保持单源；槽位文法是新增机制，以标记线与托管块先例为界；占位符钩子设计上就是提交摩擦，唯一的缓解是诊断本身即说明。
