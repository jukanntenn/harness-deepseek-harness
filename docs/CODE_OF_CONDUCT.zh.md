# 贡献者公约行为准则

[English](CODE_OF_CONDUCT.md) | 中文

## 我们的承诺

作为成员、贡献者和领导者，我们承诺使参与我们社区的每个人都不受骚扰，无论年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、个人外貌、种族、种姓、肤色、宗教信仰或性认同与性取向。

我们承诺以有助于营造开放、友好、多元、包容、健康社区的方式行动和互动。

## 我们的准则

有助于为我们的社区营造积极环境的行为示例包括：

- 对他人展现同理心和善意
- 尊重不同的意见、观点和经历
- 给予并优雅地接受建设性反馈
- 为自己的错误承担责任，向受影响者道歉，并从中学习
- 着眼于对整个社区最有利的事，而不仅仅是对我们个人有利

不可接受的行为示例包括：

- 使用性化的语言或意象，以及任何形式的性关注或性示好
- 恶意挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人的私人信息，例如物理地址或电子邮件地址
- 其他在职业场合中可被合理认定为不当的行为

## 执行责任

社区负责人有责任澄清并执行我们的可接受行为标准，并针对其认为不当、威胁、冒犯或有害的行为采取适当且公正的纠正措施。

社区负责人有权利也有责任移除、编辑或拒绝与本行为准则不一致的评论、提交、代码、wiki 编辑、议题及其他贡献，并会在适当时机说明审核决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公开场合正式代表社区的情形。代表社区的情形包括：使用官方电子邮件地址、通过官方社交媒体账号发帖，或在线上或线下活动中担任指定代表。

## 执行

如发现辱骂、骚扰或其他不可接受的行为，可向负责执行的社区负责人举报，联系方式：jukanntenn@outlook.com。所有投诉都将得到及时、公正的审查与调查。

所有社区负责人都有义务尊重任何事件举报者的隐私与安全。

## 执行指南

社区负责人将遵循以下「社区影响指南」来认定违反本行为准则的行为的后果：

### 1. 纠正

**社区影响**：使用不当语言，或其他被社区认定为不专业或不受欢迎的行为。

**后果**：社区负责人给予私下书面警告，明确说明违规性质并解释该行为为何不当。可要求公开道歉。

### 2. 警告

**社区影响**：通过单一事件或一系列行为造成的违规。

**后果**：给予带有后果的警告。在规定时间内，不得与相关人员互动，包括未经请求而联系执行行为准则的人员。这包括避免在社区空间以及社交媒体等外部渠道的互动。违反这些条款可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在规定时间内临时封禁与社区的任何互动或公开交流。在此期间，不得与相关人员公开或私下互动，包括未经请求而联系执行行为准则的人员。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：表现出违反社区标准的行为模式，包括持续的不当行为、骚扰某一个人，或对某类个体的攻击或贬损。

**后果**：被永久禁止在社区内进行任何形式的公开互动。
