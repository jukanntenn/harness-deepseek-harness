# 支持指南

[English](SUPPORT.md) | 中文

## 去哪获得帮助

| 你的情况 | 去处 |
|---|---|
| 使用与采纳问题——如何接 prek、配对契约、门禁配置 | [Discussions](https://github.com/jukanntenn/harness-deepseek-harness/discussions) 问答区 |
| 可复现缺陷与具体功能请求 | [Issues](https://github.com/jukanntenn/harness-deepseek-harness/issues)，用对应模板 |
| 安全漏洞 | 私密漏洞报告——见[安全策略](SECURITY.zh.md) |

提问欢迎英文或中文；代码、提交与评审的工作语言仍是英文。

## 什么样的缺陷报告可操作

一句话错误结果、最小复现、环境版本——恰好是 Bug issue 模板的三个必填位。细节由模板承载，本页不重复。

## 我们帮不上的

prek、uv 或 GitHub Actions 本身的缺陷属于它们的上游仓库——本项目的门禁在其上运行，在这里报也修不了。使用方仓库如何制定自己的治理规则，是使用方自己的决策；一般性讨论欢迎去 Discussions。支持是社区尽力而为：无商业支持、无 SLA。
