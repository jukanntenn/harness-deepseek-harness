## Where to get help

| Your situation | Where to go |
|---|---|
| Usage and adoption questions — wiring prek, the pairing contract, gate configuration | [Discussions](https://github.com/jukanntenn/harness-deepseek-harness/discussions), Q&A category |
| Reproducible defects and concrete feature requests | [Issues](https://github.com/jukanntenn/harness-deepseek-harness/issues) with the matching template |
| Security vulnerabilities | Private vulnerability reporting — [SECURITY.md](SECURITY.md) |

Questions in English or Chinese are both welcome; the working language for code, commits, and reviews remains English.

## What makes a bug report actionable

One sentence naming the wrong result, a minimal reproduction, and the environment versions — exactly the three slots the Bug issue template asks for. The template carries the detail; this page does not repeat it.

## What we can't help with

Defects in prek, uv, or GitHub Actions themselves belong to their upstream repositories — this project's gates run on top of them and cannot fix them there. How a consuming repository shapes its own governance rules is that repository's decision; general discussion is welcome in Discussions. Support is community best-effort: no commercial support and no SLA.
